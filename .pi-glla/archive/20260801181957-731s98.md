## Objective

> FactoryNote MVP 뷰어의 Stage 3(모듈)·Stage 4(클래스)를 마크다운 텍스트에서 **다중 섹션 인터랙티브 그래프 에디터**로 전환한다. (현재 ADR-005 로 미뤄둔 그래프 에디터를 본구현.)

(1) **뷰어(`prototypes/plan-page-mockup`)** — Stage 3/4 일 때 기존 `ModuleDesign`/`Classes` react-flow 에디터를 **데이터 주도**로 동작하도록 개조:
- **다중 섹션**: 한 단계에 여러 관계도 섹션(예: 프론트엔드/백엔드/인터). 탭 또는 스택으로 전환. 섹션 추가·이름변경·삭제 UI(사용자 관리). 각 섹션은 **독립 그래프**(교차 관계는 별도 섹션으로 표현).
- **CRUD(목업 풀패리티)**: 노드/엣지 우클릭 컨텍스트 메뉴(빈공간=추가·노드=제거·엣지=반전/제거), 노드 드래그, 핸들 연결=의존 추가. 상세 패널 편집 — 모듈(이름/계층/역할), 클래스(이름/모듈/속성/메서드 + **모듈 그룹 parent-child 계층** + `NodeResizer`). 노드/엣지 코멘트 pending 큐.
- Stage 1/2/5/6 은 기존 마크다운 `PlanPage` 유지.

(2) **직접 편집 → 에이전트 채택**: 사용자가 그래프를 직접 편집하고 게이트 제출(확정/수정지시) 시 **편집된 그래프 전체(sections)** 를 `/api/decision` 로 POST. 에이전트(drivePlan)가 이를 새 산출물로 저장(채택). 확정=다음 단계, 수정지시=현 단계 유지(+코멘트), 정정=이전 단계. (게이트 거쳐 채택하므로 5대 원칙 위반 아님.)

(3) **데이터 모델**: Stage 3/4 산출물을 마크다운에서 **다중 섹션 그래프 JSON** 으로 변경 — `.factorynote/<feature>/03-modules.json`·`04-classes.json`, 각 = `{ sections: [{ id, title, nodes: [...], edges: [...] }] }`. 에이전트는 **의미 구조 JSON**(섹션+노드+엣지, 위치 생략 가능)을 `artifactMd` 로 생성하고 뷰어가 자동 배치(grid/dagre 기본).

(4) **코어/확장**: `stages.ts` 의 Stage 3/4 `format`/`designPrompt`/`artifactFile` 갱신(.json); `gate-server` `/api/state`·`/api/decision` 에 `graphSections` 확장; `drivePlan` 이 그래프 단계 결정 시 편집된 `graphSections` 를 `.json` 산출물로 저장 + verdict 전이.

범위 밖: 섹션 간 교차 엣지(섹션은 독립), 정교 자동 레이아웃(기본 grid/dagre 이상), Stage 1/2/5/6 변경(마크다운 유지), Codex/Claude 어댑터.
