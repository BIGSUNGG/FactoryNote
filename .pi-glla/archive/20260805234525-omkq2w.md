## Objective

> FactoryNote 웹 게이트를 "단계마다 새 서버·새 포트·새 탭" 모델에서 **하나의 플랜(기능) 전체에 걸쳐 하나의 영속 게이트 서버(안정 포트)** 모델로 전환한다.

구체 동작:
- `runGate`가 단계마다 `createServer`→`listen(0)`→`openBrowser`→`server.close()` 하는 것을 폐지. 대신 기능(feature) 단위로 **하나의 영속 서버**를 시작해 재사용하고, `runGate`는 그 서버에 "이번 단계 결정 대기"만 등록한다. 서버는 **플랜 완료(done)·중단(abort)·타임아웃** 시에만 종료한다.
- 브라우저(탭) 자동 오픈은 **플랜의 첫 게이트에서 1회만**. 이후 단계에서는 새 탭을 열지 않는다.
- 사용자가 한 단계를 확정(POST /api/decision)하면 같은 탭이 '✓ N단계 확정 — 다음 준비 중…' 상태로 전환해 `/api/state`를 폴링한다. 에이전트가 다음 단계 산출물을 준비(state 갱신)하면 **같은 탭에서 자동으로 다음 단계 내용으로 교체**한다.
- 다음 단계가 준비되면 탭이 백그라운드일 수 있으므로 **적극 알림**(Web Notification API + 탭 타이틀 점멸/포커스)로 사용자에게 알린다. (조용한 갱신이 아님.)

범위 밖(명시적 제외): pi 프로세스 재시작 후 영속 서버 재연결(기존 인터럽트 복구 경로가 재오픈), 3단계 파이프라인 의미·`GateDecision`/`/api/*` API 형태·상태기계 변경, 다중 탭 동기화.
