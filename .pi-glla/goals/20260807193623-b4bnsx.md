## Objective

> `/factorynote auto [on|off]` 서브커맨드를 구현한다 — auto-advance(게이트 자동 승인)를 토글·명시 설정한다. 기본 OFF.

auto ON이면 drivePlan은 매 단계 게이트에서 runGate의 사용자 결정 블로킹 대기를 하지 않고 즉시 confirm 반환한다. 단, 게이트 서버와 브라우저는 열어 3단계 산출물 진행을 실시간 관찰할 수 있게 한다(관찰용 오픈, 결정 대기 없음 — 관찰용 헬퍼를 gate-server.ts에 runGate와 별도 export). auto ON 시 "⚠ auto-advance 활성화 — 게이트 우회" 경고 notify.

autoAdvance는 planMode와 동일한 세션 메모리(let autoAdvance = false)로 가고, 파이프라인 완료(done) 시 planMode 자동 해제(#5)와 함께 자동 해제한다.

범위는 pi-adapter 레이어에 한정 — index.ts(명령·상태·drivePlan에 autoAdvance 전달), plan-tool.ts(DrivePlanInput.autoAdvance 추가 + runOpenGate 우회 분기), gate-server.ts(관찰용 오픈 헬퍼). @factorynote/core 상태기계와 기존 runGate HTTP 블로킹 로직은 건드리지 않는다.

문서: vault/04-development Changelog.md + Dev-Log.md 갱신, vault/90-meta/usage-guide.md에 auto 모드를 개발/테스트용 탈출구(escape hatch)로 한 줄 명시(doc-workflow 규정).

범위 외: autoAdvance 영속 저장(세션 간 유지) 없음, bin/factorynote.mjs CLI에 auto 상태 표시 추가 안 함, auto를 영구 기능으로 다루는 ADR는 후속.
