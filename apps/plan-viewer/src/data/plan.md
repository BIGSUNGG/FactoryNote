# 인증 모듈 — Stage 1 요청 이해

> **상태**: 검토 대기 · **담당**: Backend · **우선순위**: 🔴 High

## 📋 요구사항 명세

사용자가 이메일/비밀번호로 가입·로그인하고, 비밀번호는 안전하게 저장된다.
인라인 강조는 **굵게**, *기울임*, ~~취소선~~, `인라인 코드`, [링크](https://example.com) 로 표현한다.

### 기능 요구사항

- 이메일·비밀번호 회원가입
- 비밀번호는 **bcrypt 해싱** 후 저장
- 로그인 성공 시 JWT 세션 발급

### 비기능 요구사항

1. 로그인 응답 200ms 이내 (p95)
2. 비밀번호 평문 절대 로깅 금지
3. JWT 수명·갱신 주기 명시

## ✅ 구현 체크리스트

- [x] bcrypt cost=12 적용 검증
- [ ] JWT 만료/갱신 정책 정의
- [ ] 감사 로그 평문 제외

## 🔧 핵심 로직

```ts
function hashPassword(pw: string): string {
  return bcrypt.hashSync(pw, 12);
}

// 호출 예: const hash = hashPassword(raw);
```

인라인으로 `hashPassword()` 함수를 호출한다.
