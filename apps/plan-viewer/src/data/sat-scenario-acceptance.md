# 위성 문서 — 동작 시나리오 · 수용 조건

> **위성 design 에이전트**: scenario-acceptance · 주 문서(draft.md)와 병렬 작성(ADR-031)

## S1 회원가입

1. 사용자가 이메일·비밀번호 제출.
2. 서버는 bcrypt(cost=12) 해시 후 저장.
3. **수용 조건**: 중복 이메일이면 409 + 안내 메시지.

## S2 로그인

1. 이메일·비밀번호로 인증 요청.
2. 해시 비교 성공 시 JWT 세션 발급.
3. **수용 조건**: 응답 200ms 이내(p95), 실패 시 401(사유 비노출).

## S3 인증 실패

- 존재하지 않는 이메일과 잘못된 비밀번호를 **동일한 401 응답**으로 처리(계정 열거 방지).
- 연속 실패 5회 시 일시 잠금 — 감사 로그에 기록(평문 제외).
