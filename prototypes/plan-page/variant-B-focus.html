요구사항 명세

사용자 요청을 기능·비기능 요구사항으로 분해하고, 범위·가정·제약을 명시한다. 이 산출물이 확정되어야 Stage 2(시나리오)로 진입한다.

⚙️ 기능 요구사항

FR-1이메일·비밀번호 회원가입기능
FR-2비밀번호 bcrypt 해싱 (cost ≥ 12)보안
FR-3로그인 성공 시 JWT 세션 발급기능

NFR-2비밀번호 평문 절대 로깅 금지보안
