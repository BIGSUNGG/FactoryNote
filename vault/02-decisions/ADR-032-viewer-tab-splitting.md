# ADR-032: 브라우저식 탭 분할(무한 중첩·드래그 드롭 존·우클릭 메뉴)

> **TL;DR**: 문서 뷰어 탭(ADR-031)을 브라우저처럼 분할한다. 탭을 드래그해 대상 영역의 좌/우/상/하 드롭 존에 놓으면 분할·탭 이동, 중앙에 놓으면 해당 영역으로 탭 이동(병합), 탭 우클릭 메뉴로는 탭을 복제해 4방향 분할한다. 분할은 무한 중첩(이진 트리), 영역별 탭 스트립, divider 드래그로 비율 조정. 마지막 탭이 닫힌 영역은 제거된다. 상태는 세션 내 메모리만(새로고침 시 단일 뷰 복귀).

## 날짜

## 맥락 (Context)

ADR-031 로 문서 + 그래프 상세 탭이 생겼지만 한 번에 탭 하나만 볼 수 있어 문서와 그래프(또는 그래프끼리) 나란히 비교할 수 없었다. 사용자는 "대부분의 브라우저처럼" — 탭 드래그 분할 + 우클릭 팝업 분할 버튼 — 동작을 요구했다. 협의에서 4결정 확정: (1) 무한 중첩 분할(Chrome 모델), (2) 영역별 탭 스트립, (3) 문서 탭 포함 전 탭 분할 가능, (4) 세션 내 상태만(영속화 없음).

## 결정 (Decision)

1. **레이아웃 모델 = 이진 분할 트리**: `leaf`(탭 목록 + 활성 탭)와 `split`(방향 h|v, 비율 ratio, 자식 2개)의 재귀 구조. 무한 중첩을 지원하면서 drop 위치 계산·렌더가 단순한 최소 모델. 순수 변환은 `lib/splitLayout.js`(viewerTabs.js 패턴, ADR-031), 렌더는 `components/SplitNode.jsx` 재귀 컴포넌트, 상태 소유는 `PlanPage`.
2. **드래그 분할**: 탭 `dragstart` 동안 모든 leaf 에 5개 드롭 존 오버레이(좌/우/상/하/중앙) 표시. 가장자리 드롭 = 그 방향으로 분할하며 드래그한 탭을 새 영역으로 **이동**, 중앙 드롭 = 대상 영역으로 탭 **이동**(병합). 드래그 상태(dataTransfer 대신 React 상태)로 happy-dom 자체체크 가능.
3. **우클릭 메뉴 분할**: 탭 우클릭 → "왼/오른/위/아래로 분할" 4항목 메뉴. 클릭 시 탭을 **복제**해 새 영역 생성(브라우저의 'Split' 동작 — 원본 유지). 바깥 클릭·Esc 로 닫힘.
4. **문서 탭(pinned) 규칙 완화**: 기존 '닫기 불가'를 '레이아웃 전체의 마지막 1개만 닫기 불가'로 완화 — 분할로 문서 탭이 복제된 사본은 닫을 수 있고, 마지막 탭이 닫힌 영역은 제거·트리가 축소된다(collapse). 문서 뷰가 완전히 사라지는 것만 방지.
5. **비율 조정**: split 노드 사이 divider 를 포인터 드래그로 조정(ratio 0.15~0.85 클램프).
6. **상태 수명**: 세션 내 메모리만 — localStorage 없음. 새로고침·게이트 재오픈 시 단일 뷰 복귀(ADR-031 탭 수명과 동일).

## 이유 (Rationale)

- 이진 트리 모델: VSCode 식 임의 격자보다 표현력 대비 복잡도가 낮고, 브라우저(Chrome)와 동일한 구조. 영역 제거 시 자식 하나로 축소(collapse)해도 트리가 깨지지 않는다.
- 드래그 상태를 dataTransfer 대신 React 상태로: 테스트(happy-dom)에서 DragEvent 구성이 불필요하고 드롭 존 하이라이트 렌더와 같은 소스를 쓴다.
- pinned 완화는 '영역 = 탭 0개면 제거'라는 브라우저 규칙과 '문서 탭 고정'의 충돌 해결 — 두 규칙 모두 최소 침범으로 유지.
- 분할 방향 4방향 전부 + divider 리사이즈: '브라우저처럼' 요구의 기본 동작이라 범위 포함.

## 대안 (Alternatives)

- **2분할만(좌우 또는 상하 1회)**: 구현은 절반이지만 사용자가 명시적으로 브라우저식 무한 중첩을 선택해 배제.
- **공유 탭 목록 + 2뷰어**: 탭 스트립이 하나라 브라우저식 영역별 탭 구성과 다르고, 탭 이동 의미가 사라져 배제.
- **localStorage 영속화**: 게이트 페이지는 로드마다 서버 상태가 동기되는 특성상 복원 가치가 낮아 배제(세션 내만).
- **외부 분할 라이브러리**: 신규 의존성 금지 + 이진 트리 직접 구현이 수십 줄 수준이라 배제.

## 결과 (Consequences)

- 신규: `lib/splitLayout.js`(순수 변환) · `components/SplitNode.jsx`(재귀 렌더 + 드롭 존 + divider) · 자체체크 11건(splitLayout 순수 7 + SplitTab 렌더 4).
- 변경: `PlanPage.jsx`(flat 탭 상태 → 분할 트리 상태, 우클릭 메뉴 포털) · `TabBar.jsx`(드래그·우클릭 props 추가, 기존 동작 무변경) · `styles/layout.css`(분할 트리·드롭 존·divider·메뉴 스타일).
- 코어 패키지·게이트 서버·API 무변경 — 뷰어 전용 변경(ADR-023·ADR-031 과 동일 경계).
- 테스트 뷰어 데모(ADR-031-viewer-test-viewer-rule): `plan.md` 예시 문서의 기존 그래프 참조 3개로 분할 데모 가능 — 시나리오·예시 문서 변경 불필요(`bun run dev` → 그래프 더블클릭으로 탭 → 드래그/우클릭 분할).
