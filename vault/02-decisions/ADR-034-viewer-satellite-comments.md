# ADR-034: 위성 문서 탭 코멘트 활성화(주 문서와 동일 채널)

> **TL;DR**: [[ADR-033-viewer-multi-doc-tabs]] 의 '위성 탭은 읽기 전용(코멘트 불가)' 제약을 폐지한다. 위성 design 문서 탭도 주 문서 탭과 **같은 코멘트 스택**(블록·셀·범위 코멘트 — `comments` 상태·`addComment`·`activate`·`onRangeComment`)을 공유한다. 읽기 전용(이전 단계 보기)·scroll-spy·그래프 제약은 유지.

## 상태

accepted — [[ADR-033-viewer-multi-doc-tabs]] 결정 4의 위성 코멘트 금지 조항을 대체

## 날짜

2026-08-19

## 맥락 (Context)

다중 문서 뷰어(ADR-033)는 위성 design 문서를 탭으로 표시하되 **읽기 전용 렌더**로 두었다 — 코멘트 채널을 게이트·검증·승격의 기준인 주 문서에 한정하기 위해서였다. 그러나 사용자가 테스트 뷰어에서 위성 탭을 열어 블록을 클릭했을 때 코멘트 팝업이 전혀 나타나지 않는 것을 **결함으로 보고**했다. 위성 문서는 리뷰 대상 산출물(리뷰어가 읽고 코멘트로 지적)이며, 주 문서에 병합되지 않은 별도 파일이라 블록 단위 의견을 남길 방법이 없어 개선 요구가 나왔다.

게이트 결정(확정/수정/회귀)은 여전히 주 문서를 기준으로 하므로, 위성 코멘트는 에이전트 수정 프로세스에서 참고 코멘트(채팅 회신)로 취급되기에 충분하다 — 실서버는 위성 파일을 피처 루트에서 읽고 재작성 라운드가 위성 에이전트를 다시 스폰하므로, 파일명이 코멘트에 구분만 되면 반영 경로가 존재한다.

## 결정 (Decision)

1. **위성 탭 = 주 문서와 동일 코멘트 스택**: `PlanPage` 의 위성 `Document` 렌더가 no-op 핸들러(`onActivate={() => {}}` 등) 대신 주 문서와 같은 `comments`·`onAddComment`(실시간 채팅 전달 포함)·`onActivate`(토글 + `onActiveBlock` 보고)·`onRangeComment`(범위 하이라이트 + 팝오버)를 사용하고 `activeTargetId` 도 공유한다. 주 문서와 위성 모두 동일 `comments` 배열에 적재 — 위성 블록 id 는 위성 md 파싱(자체 시퀀스)이라 표시 충돌이 없다.
2. **유지되는 제약**: 읽기 전용 모드(이전 단계 보기)는 `commentFreeze` 로 동일하게 코멘트 잠금 · scroll-spy 는 주 문서 기준 Toc 만(ADR-033 결정 5 유지 — 위성 탭에 `onActiveHeading` 미전달) · 그래프 없음(위성 그래프 금지, ADR-031) · 게이트·검증·승격·확정은 주 문서 기준 그대로.
3. **블록 스코프는 파일 미구분**: 위성 코멘트의 채팅 `blockId` 는 위성 블록 id 를 그대로 사용(주 문서와 동일 포맷). 파일명 구분(예: `doc:<파일>:b3`)은 코멘트가 참고 채널인 현재 단계에서 과잉 — 에이전트가 위성 파일을 이미 컨텍스트로 보유하므로 블록 id 는 근사 지시자로 충분(주 문서 블록 id 와 동일 취급).

## 이유 (Rationale)

- 위성 문서는 리뷰 대상 — 코멘트 불가는 사용자 워크플로(블록 단위 지적)를 막는 결함으로 인지됐다. 주 문서와 스택을 공유하는 것이 코멘트 모델을 확장하지 않는 최소 변경이다.
- 게이트 단일 진실(주 문서)은 건드리지 않는다. 위성 코멘트는 채팅 회신으로 에이전트에 전달되어 재작성 라운드(주 + 위성 재스폰)에서 반영 재료가 된다.
- scroll-spy·Toc 는 다중 문서 헤딩 중첩(ADR-033에서 범위 밖으로 둔 문제)의 재개 없이 주 문서 기준 유지.

## 대안 (Alternatives)

- **위성 코멘트 모델 분리(파일별 코멘트 스토어)** — 현재 뷰어 코멘트 상태는 단일 배열이라 파일별 분리는 상태 확장이 필요. 표시가 단일 배열 관통으로 충분하므로 배제.
- **위성 코멘트 blockId 에 파일 접두** — 에이전트가 블록 소속 파일을 식별할 수 있으나, 코멘트가 참고 채널인 범위에서 구분 부가가치가 낮아 배제(필요 시 후행).
- **위성 승격·게이트 포함** — ADR-031의 '주 문서 단일 진실' 계약 변경으로 스코프가 커져 배제.

## 결과 (Consequences)

- `PlanPage.jsx` 위성 탭 렌더가 읽기 전용 no-op 의존에서 주 문서 동일 핸들러로 교체 — 블록·셀·범위 코멘트가 위성 탭에서 동작.
- 테스트 뷰어: mock Stage 1 위성 문서 2종에서 바로 재현 가능(블록 클릭 → 팝오버).
- 자체체크: `SplitTab.test.jsx` 에 위성 탭 블록 클릭 → 팝오버 오픈·재클릭 토글 닫힘 회귀 가드 1건 추가, 283 pass(기존 261 + 22). `bun run typecheck` 0 종료.
