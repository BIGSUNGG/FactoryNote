# 모듈 설계 페이지 핵심 기능 — 인터랙티브 관계도 에디터

FactoryNote Plan 뷰어의 **Stage 3(모듈 아키텍처)** 산출물 페이지에 반드시 포함되어야 하는 기능을 정의한다. React 목업(`prototypes/plan-page-mockup/`의 `#/modules`)에서 동작을 검증했으며, 향후 본 구현에서도 이 사양을 준수해야 한다.

> plan 페이지([[03-design/plan-page/core-features|core-features (plan-page)]])가 마크다운 **문서** 중심이라면, 모듈 설계 페이지는 **인터랙티브 관계도(그래프 에디터)** 중심이다. 노드·엣지를 직접 조작해 구조를 설계·수정하며, 코멘트 → '수정 지시' 일괄 적용 모델은 동일하다.

> **배경**: Plannotator 분석([[plannotator-plan-page]])에서 확인한 구조 시각화 + FactoryNote 6단계 모델([[multi-agent-pipeline]]). 초기 목업은 mermaid(정적 자동 레이아웃)였으나, **노드 이동·관계 편집** 요구로 인터랙티브 그래프 라이브러리(목업은 [react-flow](https://reactflow.dev/))로 전환했다.

---

## 기능 1 — 인터랙티브 관계도 렌더링

### 요구

산출물(모듈 구조도)을 **직접 조작 가능한 노드-엣지 그래프**로 렌더링한다.

### 사양

- **그래프 라이브러리**: 드래그·핸들 연결·줌을 내장한 인터랙티브 에디터(목업은 react-flow). 정적 자동 레이아웃(mermaid) ❌.
- **모노톤 톤**: 노드(흰 배경·검정 보더)·엣지(검정 선)·핸들(검정 점). 계층(API·Service·Repository·Util·External)은 색이 아닌 **라벨**으로 구분.
- 노드 모양: 일반 모듈(사각형) · 외부 시스템(실린더/dashed). 계층이 `External`이면 자동으로 외부 모양.
- **데이터 주도**: `nodes`/`edges` state로부터 그래프 생성. 하드코딩 이미지 ❌.
- 보조: 미니맵(MiniMap)·줌 컨트롤.

---

## 기능 2 — 모듈(노드) 상세·코멘트·편집

### 요구

노드 클릭 → 우측 상세 패널에서 **역할·의존 목록 확인 + 코멘트 + 인라인 편집**.

### 사양

- 상세: 모듈명 · 계층(select) · 역할(input) — **모두 편집 가능**(변경이 즉시 노드에 반영).
- 관련 의존 목록: 나가는(→)·들어오는(←). 각 행 클릭 → 의존 상세. 모듈명 클릭 → 모듈 이동.
- 코멘트는 모듈 단위(`comments[id]`), pending 큐.
- 노드 id와 표시명(label) 분리(`labelOf` 헬퍼) — 이름을 바꿔도 의존이 꺠지지 않음.

---

## 기능 3 — 의존(엣지 A→B) 상세·코멘트·편집

### 요구

**의존 관계 자체**(A→B)의 설명·코멘트 확인 및 편집. 노드보다 세밀한 관계 단위 검토.

### 두 진입점

1. **그래프 엣지 클릭** → 의존 상세.
2. **모듈 상세의 의존 행 클릭** → 의존 상세.

### 의존 상세 패널

- `from → to` (양쪽 모듈명 클릭 시 이동).
- **의존 설명 편집**(input, 즉시 반영).
- 코멘트 리스트 + 입력. 코멘트 키 = `"${from}->${to}"`.

---

## 기능 4 — 그래프 편집 (노드·엣지 CRUD) — 핵심

### 요구

노드와 의존을 **직접 생성·수정·제거**해 구조를 설계한다. 모든 편집 동작은 **우클릭 컨텍스트 메뉴**로 통일(별도 버튼 ❌).

### 우클릭 컨텍스트 메뉴 (위치별)

| 우클릭 위치 | 메뉴 |
| --- | --- |
| **빈 공간(캔버스)** | ＋ 모듈 추가 |
| **노드(모듈)** | ✕ 모듈 제거 |
| **엣지(의존)** | ↔ 의존 방향 반전 · ✕ 의존 제거 |

- 메뉴는 우클릭한 **화면 좌표**에 팝업(`document.body` portal + `fixed`). 항목 클릭 시 액션 후 닫힘.
- 닫기: 메뉴 외부 클릭 · 다른 우클릭 · ESC. (닫기 리스너는 `setTimeout`으로 현재 우클릭 이벤트 사이클 뒤에 등록 — 메뉴가 즉시 닫히지 않도록.)

### 편집 동작

- **노드 이동**: 드래그.
- **노드 생성**: 빈 공간 우클릭 → 새 모듈(기본 이름·계층·랜덤 위치). 생성 후 상세에서 편집.
- **노드 제거**: 노드 우클릭 → 제거. **연결된 엣지도 함께 제거**.
- **노드 편집**: 상세에서 이름·계층·역할. 계층 `External` → 외부 모양.
- **의존 추가**: 한 노드의 하단 핸들(●) → 다른 노드 상단 핸들(●)로 드래그(`onConnect`). id = `"${from}->${to}"`.
- **의존 방향 반전**: 엣지 우클릭 → `A->B` → `B->A` (source/target 스왑).
- **의존 제거**: 엣지 우클릭.
- **의존 설명 편집**: 의존 상세 input.

### 상태

- `nodes`/`edges` React state. 모든 편집이 즉시 반영. 헤더에 모듈/의존 수 실시간 표시.

---

## 코멘트 → 일괄 적용 (수정 지시 게이트)

- 모듈·의존 코멘트는 같은 pending 큐.
- 하단 **'수정 지시 (N)'** 버튼 — N = pending 코멘트 수. 클릭 시 일괄 applied.

> **원칙 메모**: 목업은 노드/엣지 편집이 즉시 상태 반영(직접 편집). FactoryNote 5대 원칙([[project-identity]])을 지키려면 본 구현에서 **편집·코멘트 모두 '수정 지시' 큐에 담아 Design Agent가 반영**하도록 처리해야 한다. 목업은 편집 인터랙션 데모.

## 향후 본 구현 필수 요구사항 (체크리스트)

### 관계도 렌더링

- [ ] 인터랙티브 그래프 에디터(드래그·줌·핸들 내장)
- [ ] 모듈·외부시스템 모양 구분 (계층 External → 외부 모양)
- [ ] `nodes`/`edges` 데이터 주도 (하드코딩 ❌)
- [ ] 미니맵·줌 컨트롤

### 노드(모듈) — 상세·편집·CRUD

- [ ] 노드 클릭 → 상세 + 코멘트
- [ ] 상세에서 이름·계층·역할 **편집** (즉시 반영)
- [ ] 노드 id·label 분리 (이름 변경해도 의존 유지)
- [ ] **빈 공간 우클릭 → 모듈 추가**
- [ ] **노드 우클릭 → 모듈 제거** (연결 엣지 동반 제거)
- [ ] 노드 드래그 이동

### 의존(엣지) — 상세·편집·CRUD

- [ ] 의존 데이터에 설명(`desc`)
- [ ] 엣지 클릭 / 의존 행 클릭 → 의존 상세
- [ ] 의존 상세에서 설명 **편집**
- [ ] **핸들 연결 드래그 → 의존 추가** (`onConnect`)
- [ ] **엣지 우클릭 → 방향 반전 / 제거**

### 우클릭 컨텍스트 메뉴

- [ ] 빈 공간/노드/엣지별 적절한 메뉴
- [ ] 우클릭 화면 좌표에 팝업 (portal + fixed)
- [ ] 외부 클릭·ESC로 닫기 (닫기 리스너는 현재 이벤트 뒤로)

### 공통

- [ ] 모듈·의존 코멘트 같은 pending 큐 → '수정 지시' 일괄 applied
- [ ] 편집·코멘트를 Design Agent 제안/명령으로 처리 (5대 원칙)
