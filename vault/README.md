# FactoryNote 문서 볼트

FactoryNote 개발에 관련된 모든 문서를 작성·관리하는 Obsidian 볼트다.
코드와 같이 버전 관리되며, 기획·설계·결정·개발·문제를 항상 최신으로 유지한다.

이 볼트는 **진실의 원천(source of truth)**이다. graphify가 생성하는
`graphify-out/` 그래프는 본 볼트와 코드를 입력으로 만든 재생성 산출물이다.
